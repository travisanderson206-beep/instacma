# INSTA CMA

AI-powered Comparative Market Analysis tool. Enter a property address and get instant valuation, comparable sales with Redfin/Zillow links, market health visualization, and a downloadable PDF report.

Built with vanilla HTML/CSS/JS, GSAP animations, Gemini 2.0 Flash + Google Search via n8n webhook pipeline. Deployed on Cloudflare Pages.

**Live:** https://instacma.pages.dev
